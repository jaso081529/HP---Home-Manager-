LOKALE DATEN

Import, Export & Sicherung

Persönliche Daten werden nicht mit GitHub synchronisiert. Du entscheidest selbst, ob du eine Sicherungsdatei exportierst.

Privat by Design: Einträge, Namen und Notizen werden ausschließlich lokal im Browser gespeichert. Der öffentliche App-Code enthält keine Haushaltsdaten.

Sicherung

JSON enthält alle lokalen App-Daten und Einstellungen. CSV ist praktisch für Tabellenprogramme.

Wiederherstellen

Importiert ausschließlich eine von dieser App erzeugte JSON-Datei. Vorhandene Daten können ergänzt oder ersetzt werden.

Haushalt

Namen sind optional. Für neutrale Auswertungen reichen „Person A“, „Person B“ usw.

Ampel-Regeln

Die Ampel basiert auf erledigten Aufwandspunkten im Verhältnis zu allen protokollierten Punkten des Zeitraums.

Aufwandspunkte

Die Punkte ersetzen eine Stoppuhr. So können viele kleine und wenige große Tätigkeiten trotzdem sinnvoll zusammengefasst werden.
